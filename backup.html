Article Backup & Recovery

Protect the articles created with your local Starkon editor. Export a backup file and use it later to restore your saved stories.

1. Back up your articles

Export the locally saved stories from this browser into a JSON file that you can keep in a safe folder.

2. Restore from a backup

Select a JSON backup previously exported by this tool. The tool checks its format before saving any stories.

Important information

This tool backs up stories saved by the local article editor. It does not back up your HTML, CSS, images stored elsewhere, or your entire website project.

Keep backup files somewhere separate from your project, such as a personal backup folder or a trusted cloud drive.
